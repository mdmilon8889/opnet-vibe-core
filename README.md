# 🌐 Opnet-Vibe-Core

Welcome to the **Opnet-Vibe-Core** repository! This project is a unique blend of **Network Simulation** and **AI-driven Vibecoding** techniques.

## 🚀 Project Overview
This repository focuses on designing and analyzing network models using **OPNET Modeler**. The core philosophy here is to integrate **Vibecoding** (Prompt-based or AI-assisted coding) to simplify complex network configurations and performance evaluations.

### 🛠 Tools & Technologies
* **Simulator:** OPNET Modeler / Riverbed Modeler
* **Workflow:** Vibecoding (AI-assisted Scripting)
* **Language:** C / C++ (for OPNET logic)
* **Platform:** GitHub Mobile-First Management

## 📂 Project Structure
* `/scripts`: Contains C/C++ logic generated via Vibecoding.
* `/models`: OPNET network design files and configurations.
* `/prompts`: Documentation of AI prompts used for coding.
* `/results`: Simulation output and performance graphs.

## 🎯 Objectives
1.  To automate OPNET modeling using structured AI prompts.
2.  To analyze network latency, throughput, and packet loss.
3.  To create a reusable framework for rapid network prototyping.

## 📝 How to Use
Since this is a Vibecoding-driven project, you can find the logic flow in the `/prompts` folder. To run the simulations, import the `.project` files into your OPNET environment.
